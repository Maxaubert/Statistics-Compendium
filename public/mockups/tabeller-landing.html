Tabeller-side: 4 mockup-varianter

Bare 6 tabeller — så det blir mye tomrom på dagens 2-kolonners kort-grid. Disse fire mønstrene fyller plassen bedre, gir mer informasjon per kort, eller endrer layouten helt.

← Tilbake til appens tabeller-side

Hopp til: 1. Rich cards (sparkline) 2. Hero quick-lookup 3. List + preview 4. Wide sections
Variant 1

Rich cards med fordelings-sparkline

3-kolonners grid med visuelt rikere kort. Hver tabell får et lite distribusjons-spark inline (silhuett av tetthetsfunksjonen), code, formell navn og I/O-pills. Tetter informasjon, varmere visuelt.

Sparkline-en kommuniserer fordelingsformen umiddelbart. 3 kolonner reduserer empty space. Lite vertikal scroll.

Mer kompleks å implementere (SVG-graf per fordeling). Sparklines skalerer ikke responsivt under 800px.

Variant 2

Hero quick-lookup + kompakt tabell-liste

Øverst: en stor «hurtig-oppslag»-widget for det vanligste behovet (Z-tabell). Brukeren kan slå opp uten å klikke seg inn. Under: en kompakt 2-kolonne liste med alle 6 tabeller for navigasjon.

Gir umiddelbar verdi på landingssiden — ingen klikk nødvendig for det vanligste. Fyller toppen rikt og målrettet.

Bare ÉN tabell får hurtig-tilgang. Krever beslutning om hvilken (Z er sannsynligvis riktig).

Variant 3

List + side-preview pane

Vertikal liste til venstre med alle 6 tabeller. Klikk eller hover på en tabell — preview-panelet til høyre viser detaljene + et inline lookup-widget. Bra for «utforske før du klikker dypt».

Ingen tom plass. Brukeren kan se og prøve flere tabeller raskt uten side-navigasjon.

Mer state og interaksjon. Less ideelt på små skjermer (men kan stacke).

Variant 4

Wide sections (full-width per tabell)

Hver tabell får sin egen «artikkel»-seksjon: rik beskrivelse til venstre med «når brukes den», input/output-info til høyre. Ingen tom plass; siden ser ut som en lærebok-oversikt.

Ingen tomrom. Pedagogisk: forklarer konteksten direkte. Lett å skanne med flere detaljer per tabell.

Lengre side (mer skroll). Krever ekstra "når brukes"-tekst per tabell.

Binomialtabell E.1

Kumulativ binomisk sannsynlighet

Slår opp P(X ≤ k) for binomialfordeling med valgte n og p. Tabellen forenkler beregninger som ville krevd manuelle summer av binomialledd.

Brukes tilEksamensoppgaver med fast antall forsøk og kumulative sannsynligheter — typisk «minst k» / «høyst k».
Input → output
npk → P(X ≤ k)

Poissontabell E.2

Kumulativ poissonfordeling

Slår opp P(X ≤ k) for poissonfordeling. Inputene er forventningsverdien μ (= λt for et tidsvindu) og k.

Brukes tilHendelser i et tidsvindu med kjent rate. Ofte sammen med eksponentialfordelingen.
Input → output
μk → P(X ≤ k)

Z-tabell E.3

Kumulativ standardnormalfordeling

Slår opp G(z) = P(Z ≤ z) for en gitt z-verdi. Brukes til å konvertere standardiserte normalverdier til sannsynligheter.

Brukes tilZ-tester, KI med kjent σ, og enhver oppgave hvor du standardiserer (X − μ)/σ.
Input → output
z → G(z) = P(Z ≤ z)

Z-kvantiltabell E.4

Standardnormalfordelingens kvantiltabell

Invers av Z-tabellen. Slår opp z_α slik at P(Z > z_α) = α (areal i høyre hale).

Brukes tilKonfidensintervaller (z_(α/2)) og ensidige hypotesetester (kritisk verdi).
Input → output
α → z_α

t-tabell E.5

t-fordelingens kvantiltabell

Slår opp kritiske t-verdier t_α for ulike frihetsgrader ν og signifikansnivåer α.

Brukes tilt-tester og KI når populasjonsvariansen er ukjent (typisk når n < 30).
Input → output
dfα → t_(α, df)

Kjikvadrattabell E.6

Kjikvadratfordelingens kvantiltabell

Kritiske χ²-verdier for ulike frihetsgrader og signifikansnivåer.

Brukes tilGoodness of fit, uavhengighetstester, og konfidensintervall for varians.
Input → output
dfα → χ²_(α, df)
