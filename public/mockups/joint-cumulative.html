/entry/varians-standardavvik-diskret (joint context)

Varians for diskret SV (i joint distribution)

Var(X) = Σ (x − μ_X)² · P(X = x). Bruker marginal og E[X] som forutsetninger.

Eksamen mai25 · oppgave 1b
Finn Var(X) og Var(Y) fra simultanfordelingen.
✓ 1 · Marginal ✓ 2 · E[X], E[Y] 3 · Var
Simultantabellen (med marginaler)
Y = 0Y = 1Y = 2P(X)
X = 00.100.200.100.40
X = 10.400.100.100.60
P(Y)0.500.300.201.00
Forventningsverdier (forutsetning)

μ_X = 0 · 0.40 + 1 · 0.60 = 0.60

μ_Y = 0 · 0.50 + 1 · 0.30 + 2 · 0.20 = 0.70

Var(X) — direkte form

Var(X) = (0 − 0.60)² · 0.40 + (1 − 0.60)² · 0.60

= 0.36 · 0.40 + 0.16 · 0.60

= 0.144 + 0.096 = 0.240

σ_X = √0.240 ≈ 0.4899

Var(Y) — direkte form

Var(Y) = (0 − 0.70)² · 0.50 + (1 − 0.70)² · 0.30 + (2 − 0.70)² · 0.20

= 0.49 · 0.50 + 0.09 · 0.30 + 1.69 · 0.20

= 0.245 + 0.027 + 0.338 = 0.610

σ_Y = √0.610 ≈ 0.7810

Resultat
Var(X) = 0.240 · Var(Y) = 0.610 · σ_X ≈ 0.49 · σ_Y ≈ 0.78
/entry/kovarians

Kovarians Cov(X, Y)

Mål for samvariasjon mellom to variabler i simultanfordeling.

Eksamen mai25 · oppgave 1c
Finn Cov(X, Y).
✓ 1 · Marginal ✓ 2 · E[X], E[Y] ✓ 3 · Var, σ 4 · Cov
Simultantabellen
Y = 0Y = 1Y = 2P(X)
X = 00.100.200.100.40
X = 10.400.100.100.60
P(Y)0.500.300.201.00
Forutsetninger fra forrige steg

μ_X = 0.60 · μ_Y = 0.70 · σ_X ≈ 0.49 · σ_Y ≈ 0.78

E[XY] — bruk JOINT-sannsynlighet fra simultantabellen

For en generell simultanfordeling må du bruke selve celle-sannsynligheten P(X=x_i, Y=y_j).

(0, 0): 0 · 0 · 0.10 = 0

(0, 1): 0 · 1 · 0.20 = 0

(0, 2): 0 · 2 · 0.10 = 0

(1, 0): 1 · 0 · 0.40 = 0

(1, 1): 1 · 1 · 0.10 = 0.10

(1, 2): 1 · 2 · 0.10 = 0.20

E[XY] = 0.30

Kovarians

Cov(X, Y) = E[XY] − μ_X · μ_Y = 0.30 − 0.60 · 0.70 = −0.12

Tips Hadde X og Y vært uavhengige, ville E[XY] = μ_X · μ_Y = 0.42 og Cov = 0. Avviket −0.12 viser graden av (negativ) avhengighet.
Resultat
Cov(X, Y) = −0.12
/entry/korrelasjon-joint

Korrelasjon ρ(X, Y)

Skala-uavhengig mål mellom −1 og 1. Siste steg i joint-kjeden.

Eksamen mai25 · oppgave 1d
Finn korrelasjonen ρ(X, Y).
✓ 1 · Marginal ✓ 2 · E[X], E[Y] ✓ 3 · Var, σ ✓ 4 · Cov 5 · ρ
Simultantabellen
Y = 0Y = 1Y = 2P(X)
X = 00.100.200.100.40
X = 10.400.100.100.60
P(Y)0.500.300.201.00
Forutsetninger fra de fire forrige stegene

μ_X = 0.60 · μ_Y = 0.70

σ_X ≈ 0.4899 · σ_Y ≈ 0.7810

Cov(X, Y) = −0.12

Korrelasjon

ρ(X, Y) = Cov(X, Y) / (σ_X · σ_Y)

= −0.12 / (0.4899 · 0.7810)

= −0.12 / 0.3826 ≈ −0.314

Tips |ρ| < 0.5 → svak til moderat lineær sammenheng. Negativt fortegn ⇒ omvendt assosiasjon: når X øker, har Y tendens til å minke.
Resultat
ρ(X, Y) ≈ −0.314
